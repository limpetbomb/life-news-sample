# ライフニュース 掲載企業DB 試作管理画面

地方新聞折込連合広告「ライフニュース」の掲載企業情報を管理するための、ローカルWebアプリ試作品です。

営業が広告枠販売後に企業情報を入力し、その情報をもとに以下を管理する想定です。

- 紙面制作に使う原稿情報
- Web掲載用の記事データ
- 掲載企業一覧
- CSV出力による外部ツール移行

## 起動方法

この試作品は外部DBやWordPressを使いません。ブラウザだけで動きます。

1. `life-news-admin.html` をブラウザで開きます。
2. 管理画面で掲載企業を登録、編集、削除します。
3. 必要に応じて「CSV出力」ボタンからデータを書き出します。

ローカルサーバーで確認する場合:

```bash
cd /Users/design03b/Documents/Codex/2026-06-02/d3-40-60-web-90-40/outputs
python3 -m http.server 8787
```

その後、ブラウザで以下を開きます。

```text
http://127.0.0.1:8787/life-news-admin.html
```

## 保存方式

現時点ではブラウザの `localStorage` に保存します。

- 外部DB連携なし
- サーバー不要
- 同じブラウザ内でデータを保持
- 別PCや別ブラウザとは共有されない
- 本番運用前にCSV出力や外部DB連携へ移行する前提

## 管理項目

CSV出力の列名も以下の項目に合わせています。

| 項目ID | 表示名 |
|---|---|
| `id` | レコードID |
| `issue` | 掲載号 |
| `feature` | 特集名 |
| `category` | カテゴリ |
| `companyName` | 企業名 |
| `industry` | 業種 |
| `salesPerson` | 担当営業 |
| `catchCopy` | キャッチコピー |
| `description` | 紹介文 |
| `services` | 商品、サービス内容 |
| `address` | 住所 |
| `phone` | 電話番号 |
| `website` | WebサイトURL |
| `imageUrl` | 画像URL |
| `qrUrl` | QRリンク先URL |
| `adSize` | 紙面掲載枠サイズ |
| `notes` | 備考 |

## 画面構成

### 1. 掲載企業一覧画面

登録済み企業を表形式で確認できます。

- 掲載号
- カテゴリ
- 企業名
- 業種
- 担当営業
- 紙面掲載枠サイズ
- 電話番号
- 編集、プレビュー、削除

### 2. 新規登録フォーム

右側のフォームから掲載企業情報を登録できます。

### 3. 編集画面

一覧の「編集」ボタンを押すと、登録済み情報がフォームに読み込まれます。

### 4. Web記事プレビュー画面

フォーム入力内容または登録済みデータから、Web記事の簡易プレビューを表示します。

プレビュー構成:

- 企業名
- キャッチコピー
- 紹介文
- 商品、サービス内容
- 住所
- 電話番号
- WebサイトURL
- 問い合わせ導線
- 紙面掲載号
- 特集名

### 5. CSV出力

現在の絞り込み結果をCSV出力します。

カテゴリで絞り込んだ状態で出力すれば、そのカテゴリだけのCSVを書き出せます。

## 将来のノーコード移行方針

この試作品は、Airtable、Notion、Googleスプレッドシートなどへ移行しやすいように、データを1企業=1レコードのフラットな構造にしています。

### Airtableへ移行する場合

おすすめ構成:

- Table: `Companies`
- View: `掲載号別`
- View: `カテゴリ別`
- View: `営業担当別`
- Attachment field: 画像
- URL field: WebサイトURL、QRリンク先URL
- Single select: カテゴリ、紙面掲載枠サイズ

CSVをAirtableへインポートし、列名をそのままフィールド名として利用できます。

### Notionへ移行する場合

おすすめ構成:

- Database: `ライフニュース掲載企業`
- Select: カテゴリ、掲載号、紙面掲載枠サイズ
- Text: キャッチコピー、紹介文、サービス内容
- URL: WebサイトURL、画像URL、QRリンク先URL
- Phone: 電話番号
- Person or Text: 担当営業

Notionでは各企業ページをそのまま記事原稿メモとして使えます。

### Googleスプレッドシートへ移行する場合

おすすめ構成:

- 1行=1企業
- 列名はCSV項目IDに合わせる
- `掲載号`、`カテゴリ`、`担当営業` でフィルタビューを作成
- Apps Scriptやノーコード連携でWeb掲載データへ変換

- CSVインポート
