# ライフニュース 原稿自動生成ツール 試作版

掲載企業向けのWeb記事、SNS投稿、紙面用短文を生成するローカルWebアプリです。

営業または制作が企業情報を入力すると、紙面・Web・SNSで使える文章案を生成します。現時点では外部AI APIを使わない仮実装です。入力情報をもとにしたルールベース生成のため、APIキーは不要です。

## 起動方法

ブラウザで以下を開きます。

```text
http://127.0.0.1:8787/life-news-copy-generator.html
```

ローカルサーバーを起動する場合:

```bash
cd /Users/design03b/Documents/Codex/2026-06-02/d3-40-60-web-90-40/outputs
python3 -m http.server 8787
```

## 入力項目

- 特集名
- カテゴリ
- 企業名
- 業種
- 販売商品、サービス名
- サービス内容
- 強み、特徴
- 対象顧客
- 価格帯
- 対応エリア
- 住所
- 電話番号
- WebサイトURL
- キャンペーン情報
- 掲載号
- 文章のトーン
- 生成したい文章タイプ

## 生成される文章の種類

1. 紙面用キャッチコピー
2. 紙面用短文紹介
3. Web記事タイトル
4. Web記事本文
5. SNS投稿文
6. ハッシュタグ案
7. QR誘導文
8. 営業提案用の説明文

## 生成ルール

- 入力情報から自然な日本語を生成します。
- 入力されていない内容は作りすぎません。
- 未入力の重要項目は「要確認」として表示します。
- 医療、健康、保険、法律、相続などは断定表現を避けます。
- Web記事本文は複数段落で生成します。
- SNS投稿は短めにまとめます。
- 出力欄ごとにコピーできます。
- JSONまたはCSVで出力できます。

## サンプル入力データ

以下の3件を用意しています。

- みどりマート / 食材、スーパー
- まごころ惣菜便 / 惣菜、宅配
- 青葉薬局 健康相談室 / 健康相談

## 外部AI API接続について

現時点では外部AI APIを使っていません。あとからAI APIに接続する場合は、現在の `generate(data)` 関数をAPI呼び出しに差し替える設計です。

APIキーを使う場合は、ブラウザに直接キーを書かず、以下のようなサーバー側構成にします。

```text
.env
OPENAI_API_KEY=...
```

推奨構成:

- フロントエンド: 入力フォーム、結果表示、コピー、CSV/JSON出力
- サーバー: APIキー管理、生成プロンプト作成、AI API呼び出し
- DB: 掲載企業情報、生成履歴、公開ステータス

## DBやAirtable、Notionと連携する場合

### DB連携

掲載企業DBの各レコードをこの生成ツールの入力値として渡すと、企業ごとに原稿案を生成できます。

想定フロー:

1. 掲載企業DBに企業情報を登録
2. 「原稿生成」ボタンでこのツールにデータを渡す
3. Web記事、SNS、紙面短文を生成
4. 生成文を編集
5. 掲載企業DBに生成結果を保存

### Airtable

おすすめフィールド:

- Companies table: 企業情報
- GeneratedCopy table: 生成文
- Linked record: 企業情報と生成文を紐づけ
- Select: 文章タイプ、掲載号、カテゴリ
- Long text: Web記事本文、SNS投稿文、紙面短文

### Notion

おすすめ構成:

- 掲載企業データベース
- 生成原稿データベース
- Relationで企業と生成原稿を紐づけ
- 各企業ページ内にWeb記事案、SNS案、紙面案を保存

### Googleスプレッドシート

おすすめ構成:

- 1シート目: 掲載企業情報
- 2シート目: 生成結果
- `company_id` で紐づけ
- Apps Scriptで生成ツールやAI APIと連携

## 本番化する場合の検討事項
